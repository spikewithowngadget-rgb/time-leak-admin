# TimeLeak web assets

The `web_handoff/assets/` folder and mobile ARB files referenced by
`TZ_WEB_FRONTEND.md` were not included in the supplied files or found in the
local mobile/project folders.

`brand.svg`, `onboarding-memory.svg` and `onboarding-notes.svg` are temporary,
code-native vector artwork using the specification’s colors. They are not
copies of the mobile artwork. Replace these with the original `brand.png`,
`onb1.jpg` and `onb2.jpg` when the mobile handoff is available.

The language packs in `src/i18n.ts` retain the specification’s key names and
include English, Russian, Chinese, Hindi, French, German, Spanish, Italian,
Portuguese and Arabic. These translations were authored for this web client,
because the original `app_*.arb` files were not supplied.
